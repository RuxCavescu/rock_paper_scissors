# Rock Paper Scissors

A classic Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript.

## How to Run

Since this project uses JavaScript modules, you need to serve it with a local HTTP server:

```bash
python -m http.server 8000
```

Then navigate to `http://localhost:8000`

**Note:** Simply opening `index.html` directly in the browser won't work due to CORS restrictions with JavaScript modules.
